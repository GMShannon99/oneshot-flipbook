# Sticks & Stones

*Art and Story by Jessie Grill*

A page-flip viewer for the illustrated book *Sticks & Stones*, built with
[StPageFlip](https://github.com/Nodlik/StPageFlip). Click or drag a page
corner, or use the arrow keys, to turn pages.
